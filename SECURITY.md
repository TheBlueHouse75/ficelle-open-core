# Security policy

## Supported version

Security fixes are provided for the latest published Ficelle Core release.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email
`support@ficelle.ai` with the subject `[Ficelle Security]` and include:

- the affected version and platform;
- reproduction steps or a minimal proof of concept;
- the expected impact;
- any suggested mitigation.

Do not include real API keys, license keys, customer data, or other secrets. We will
acknowledge the report privately and coordinate remediation and disclosure.
